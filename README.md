# image

Image maker. Use for any finished image — charts and graphs from real data, infographics, diagrams, illustrations, photos, OG and social cards, covers, carousels, cutouts, edits — in any repo. Fetches the numbers from the agent that owns them. Other agents call it for their images.

An agent for [hq](https://github.com/Ying-Kai-Liao/hq): a specialist that runs in Claude Code with its own memory,
skills and tools, on your own Mac.

```
hq install Ying-Kai-Liao/hq-image
```

It asks for these services, used only once you grant them (`hq auth grant image <service> <profile>`): codex.

`hq install` shows what it may do on your Mac (permissions, tools, services) before keeping it. Its memory and data
stay yours; updating it (`hq update image`) never touches them.
